НЕОН АРЕНА — МУЛЬТИПЛЕЕР

В архиве:
- server.js — игровой сервер Socket.IO
- package.json — зависимости Node.js
- public/index.html — игра

ВАЖНО:
Netlify подходит для статических сайтов, но не запускает этот Node.js сервер.
Для настоящего мультиплеера нужно разместить весь проект на хостинге Node.js, например Render.

Публикация на Render:
1. Создай GitHub-репозиторий и загрузи туда содержимое папки проекта.
2. На Render создай новый Web Service и подключи репозиторий.
3. Build Command: npm install
4. Start Command: npm start
5. После публикации открой адрес Render — игра и сервер будут работать на одном домене.
6. Отправь другу тот же адрес и одинаковый код комнаты.

Локальный запуск на компьютере:
1. Установи Node.js.
2. Открой терминал в папке проекта.
3. Выполни: npm install
4. Выполни: npm start
5. Открой http://localhost:3000

В этой версии игроки могут ходить и стрелять друг в друга. Комнаты создаются автоматически по введённому коду, максимум 8 игроков.
